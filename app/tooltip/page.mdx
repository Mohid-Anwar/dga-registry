# Tooltip

A popup that shows information related to an element when it receives keyboard focus or the mouse hovers over it, built on Radix `Tooltip`.

## Long Text

`TooltipContent` caps at a `240px` max width — longer text wraps automatically instead of stretching the tooltip across the screen.

<TooltipLongText />

## With a Title

Compose `TooltipTitle` above the description text for a two-part tooltip — the title uses the heading text color, the description uses the paragraph text color.

## Props

### Tooltip / TooltipProvider

| Prop            | Type                      | Default | Description                              |
| --------------- | ------------------------- | ------- | ------------------------------------------ |
| `delayDuration` | `number`                  | `0` (Provider) | Milliseconds before the tooltip opens on hover |
| `open`          | `boolean`                 | —       | Controlled open state                       |
| `onOpenChange`  | `(open: boolean) => void` | —       | Called when open state changes              |

### TooltipContent

| Prop         | Type                                    | Default | Description                          |
| ------------ | ---------------------------------------- | ------- | -------------------------------------- |
| `side`       | `"top" \| "right" \| "bottom" \| "left"` | `"top"` | Preferred side relative to the trigger |
| `sideOffset` | `number`                                 | `0`     | Distance in pixels from the trigger    |
| `className`  | `string`                                 | —       | Additional CSS classes                 |

### TooltipTitle

| Prop        | Type     | Default | Description                                 |
| ----------- | -------- | ------- | --------------------------------------------- |
| `className` | `string` | —       | Additional CSS classes for the title text     |
