# Tag

Displays a tag used to label, categorize, or organize content using status colors.

<DirectionToggle />

## Installation

<InstallCommand componentName="tag" />

## Variants

| Variant   | Description                  |
| --------- | ---------------------------- |
| `success` | Positive / completed state   |
| `info`    | Informational state          |
| `warning` | Cautionary state             |
| `error`   | Negative / failed state      |
| `neutral` | Default, uncategorized state |

<TagVariants />

## Outline Variants

Each variant also has an outline style with a transparent background.

<TagOutlineVariants />

## On Color

Use `on-color` variants when the tag sits on top of a colored or dark background.

<TagOnColor />

## Rounded

| Rounded | Description                      |
| ------- | -------------------------------- |
| `false` | Standard corner radius (default) |
| `true`  | Fully rounded (pill) corners     |

<TagRounded />

## Sizes

| Size | Description           |
| ---- | --------------------- |
| `sm` | 20px height           |
| `md` | 24px height (default) |
| `lg` | 32px height           |

<TagSizes />

## Props

| Prop        | Type      | Default     | Description            |
| ----------- | --------- | ----------- | ---------------------- |
| `variant`   | `string`  | `"success"` | Visual style variant   |
| `size`      | `string`  | `"md"`      | Tag size               |
| `rounded`   | `boolean` | `false`     | Corner radius          |
| `className` | `string`  | —           | Additional CSS classes |
