# Changelog

Track updates to DGA Components — new components, improvements, and fixes.

---

## August 2026

<ChangelogSection>
  <ChangelogEntry type="added" name="Tag">
    Status and category labels with multiple semantic variants, outline styles,
    sizes, and corner options.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Lightbox">
    A fullscreen image viewer with zoom, slideshow, thumbnails, and RTL support.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Recaptcha">
    Google reCAPTCHA v2 with locale support and responsive sizing.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Infinite Logo Scroll">
    An auto-scrolling logo marquee with configurable direction, speed, hover
    behavior, and custom image rendering.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Form Field">
    A reusable form-control wrapper with labels, required states, and validation
    messages.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Checkbox Group Field">
    Grouped checkbox fields with a shared label and validation message.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="File Upload Field">
    Single-file uploads with client-side type, extension, and size validation.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Collapsible">
    Collapsible content with controlled and default-open states.
  </ChangelogEntry>
  <ChangelogEntry type="added" name="Tooltip">
    Tooltips with wrapped content, DGA design tokens, and an optional title.
  </ChangelogEntry>
  <ChangelogEntry type="changed" name="Badge">
    Added chip variants for active, pressed, selected, on-color, and disabled
    states.
  </ChangelogEntry>
  <ChangelogEntry type="changed" name="Sonner (Toast)">
    Added independent mobile toast positioning.
  </ChangelogEntry>
  <ChangelogEntry type="changed" name="Select">
    Improved scroll-lock behavior for installed registry consumers.
  </ChangelogEntry>
  <ChangelogEntry type="changed" name="Collapsible">
    Made open/close animations self-contained for registry consumers.
  </ChangelogEntry>
  <ChangelogEntry type="changed" name="Documentation">
    Changes in Sidebar & general improvements made including codeblocks
  </ChangelogEntry>
  <ChangelogEntry type="fixed" name="Sonner (Toast)">
    Restricted mobile positioning to the positions Sonner actually supports on
    narrow viewports.
  </ChangelogEntry>
  <ChangelogEntry type="fixed" name="Skeleton">
    Fixed the registry install path for its stylesheet.
  </ChangelogEntry>
  <ChangelogEntry type="fixed" name="Select">
    Fixed design-token references affecting the trigger's border, background,
    and open/error states.
  </ChangelogEntry>
  <ChangelogEntry type="fixed" name="Input">
    Fixed design-token references affecting border, background, and radius
    styling.
  </ChangelogEntry>
  <ChangelogEntry type="fixed" name="Tooltip">
    Fixed dark-mode text contrast on the default tooltip style.
  </ChangelogEntry>
  <ChangelogEntry type="fixed" name="Docs Header">
    Fixed RTL alignment in the documentation header.
  </ChangelogEntry>
</ChangelogSection>
