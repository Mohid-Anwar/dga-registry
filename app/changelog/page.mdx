# Changelog

Track updates to DGA Components — new components, improvements, and fixes.

---

## August 2026

### New Components

- **Tag** — Status and category labels with success, info, warning, error, neutral, and on-color variants, each with an outline style, plus `sm`/`md`/`lg` sizes and rounded/pill corners
- **Lightbox** — Fullscreen image viewer built on `yet-another-react-lightbox` with zoom, slideshow, thumbnail sidebar navigation, and RTL support
- **Recaptcha** — Google reCAPTCHA v2 checkbox widget with locale support and a compact size on narrow viewports
- **Infinite Logo Scroll** — Auto-scrolling logo/partner marquee with configurable direction, speed, and hover slowdown; renders framework-agnostic `<img>` by default with a `renderImage` slot for `next/image` or other optimized image components

### Improvements

- **Badge** — Added `chip-primary-active`, `chip-primary-pressed`, `chip-on-color`, `chip-on-color-selected`, and `chip-disabled` chip variants, and documented them alongside the existing chip variants
- **Sonner (Toast)** — Added `mobilePosition` prop to control toast placement below the mobile breakpoint independently from desktop `position`

### Fixes

- **Sonner (Toast)** — `mobilePosition` now only accepts `"top"` / `"bottom"`, matching Sonner's own mobile behavior where toasts render full-width and left/center/right positions collapse to the same look
- **Skeleton** — Fixed registry entry for `skeleton.css` so it installs to `styles/skeleton.css` in consumer projects instead of `ui/skeleton.css`
- Fixed a hardcoded `ml-auto` in the docs header that broke RTL layouts; now uses the direction-aware `ms-auto`

---

## May 2026

### New Components

- **Navigation Menu** — Full RTL support with keyboard navigation
- **Carousel** — Embla-based with swipe and RTL direction
- **Skeleton** — Loading placeholders with RTL-aware animations
- **Sonner (Toast)** — Notification banners with 5 variants (error, warning, success, info, neutral), RTL auto-flip, customizable icons, and mobile-responsive positioning

### Improvements

- Updated all components to match latest Platforms Code design tokens
- Added IBM Plex Sans Arabic as default font
- Full RTL support across all existing components

### Infrastructure

- Added shadcn registry support (`@dga/` prefix)
- Multi-framework installation: Next.js, Vite, Laravel
- SEO optimization with structured data
