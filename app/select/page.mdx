## Placeholder Option

`SelectValue`'s `placeholder` only covers the _empty_ state — once a value is
picked there's no way back to it, since Radix has no concept of an empty option.
`SelectPlaceholderItem` adds one: it renders a muted, selectable row backed by an
internal sentinel value, and `Select` maps that sentinel back to `""` in
`onValueChange`, so your state never sees the sentinel.

<SelectPlaceholderOption />

## Props

### Select

| Prop            | Type                      | Default | Description                 |
| --------------- | ------------------------- | ------- | --------------------------- |
| `defaultValue`  | `string`                  | —       | The default selected value  |
| `value`         | `string`                  | —       | Controlled selected value   |
| `onValueChange` | `(value: string) => void` | —       | Callback when value changes |
| `disabled`      | `boolean`                 | `false` | Disables the select         |

### SelectTrigger

| Prop           | Type                | Default     | Description                                               |
| -------------- | ------------------- | ----------- | --------------------------------------------------------- |
| `size`         | `"default" \| "sm"` | `"default"` | Size variant                                              |
| `aria-invalid` | `boolean`           | —           | Shows the bottom underline in the error color permanently |
| `className`    | `string`            | —           | Additional CSS classes                                    |

## Notes

`select.tsx` ships a companion `select.css` (installed to `styles/select.css`) that fixes a Radix scroll-lock issue — `react-remove-scroll` adds `data-scroll-locked` to `<body>` while the dropdown is open, which otherwise causes a horizontal layout shift. This is imported automatically; no extra setup needed.

### SelectItem

| Prop       | Type        | Default | Description                |
| ---------- | ----------- | ------- | -------------------------- |
| `value`    | `string`    | —       | The value of the item      |
| `disabled` | `boolean`   | `false` | Disables this item         |
| `children` | `ReactNode` | —       | Item content (text, icons) |
