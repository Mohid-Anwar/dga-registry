## Positioning

Control where toasts appear with the `position` prop on `<Toaster />`. Click a position to preview it live.

| Position        | Description                |
| --------------- | -------------------------- |
| `top-left`      | Top-left corner            |
| `top-center`    | Top-center                 |
| `top-right`     | Top-right corner (default) |
| `bottom-left`   | Bottom-left corner         |
| `bottom-center` | Bottom-center              |
| `bottom-right`  | Bottom-right corner        |

Sonner renders toasts full-width below the mobile breakpoint (768px), so `left`/`center`/`right` collapse to the same look there — only the edge matters. Use `mobilePosition` to pick `"top"` or `"bottom"` for that case:

## RTL Support

Toast content renders in whatever language you pass it:

<SonnerRtl />

Positioning is separate. The `<Toaster />` is mounted once at your app root, so it
can't inherit `dir` from the element that triggered the toast — it reads direction
from context instead. Wrap your app in `<DirectionProvider dir="rtl">` and the
`Toaster` flips `left`↔`right` automatically:

<CodeBlock language="tsx" filename="app/layout.tsx" code={rtlLayoutSnippet} />

With the provider in place, `position="top-right"` renders at the top **left** — the
mirrored equivalent — so you specify positions once and they adapt per direction.
Without it, toasts stay on the LTR side even though the rest of your UI is mirrored.

`mobilePosition` is unaffected, since it only controls the top/bottom edge.

## Toaster Props

| Prop             | Type             | Default       | Description                                                    |
| ---------------- | ---------------- | ------------- | -------------------------------------------------------------- |
| `position`       | `Position`       | `"top-right"` | Toast position on desktop (auto-flipped in RTL)                |
| `mobilePosition` | `MobilePosition` | `"top"`       | Toast edge below the mobile breakpoint (`"top"` \| `"bottom"`) |

## Toast Helper Functions

| Function       | Parameters                    | Description        |
| -------------- | ----------------------------- | ------------------ |
| `toastError`   | `(message, title?, options?)` | Show error toast   |
| `toastWarning` | `(message, title?, options?)` | Show warning toast |
| `toastSuccess` | `(message, title?, options?)` | Show success toast |
| `toastInfo`    | `(message, title?, options?)` | Show info toast    |
| `toastNeutral` | `(message, title?, options?)` | Show neutral toast |

### Toast Options

| Option        | Type                  | Default         | Description               |
| ------------- | --------------------- | --------------- | ------------------------- |
| `icon`        | `IconDefinition`      | Variant default | Override the variant icon |
| `iconType`    | `"solid" \| "stroke"` | Variant default | Icon style                |
| `dismissIcon` | `IconDefinition`      | `Cancel01Icon`  | Override the dismiss icon |
