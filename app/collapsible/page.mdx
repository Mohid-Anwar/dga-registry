## Props

### Collapsible

| Prop           | Type                      | Default | Description                       |
| -------------- | ------------------------- | ------- | --------------------------------- |
| `open`         | `boolean`                 | —       | Controlled open state             |
| `defaultOpen`  | `boolean`                 | `false` | Initial open state (uncontrolled) |
| `onOpenChange` | `(open: boolean) => void` | —       | Called when open state changes    |
| `disabled`     | `boolean`                 | `false` | Disables the trigger              |

### CollapsibleTrigger

| Prop      | Type      | Default | Description                                          |
| --------- | --------- | ------- | ---------------------------------------------------- |
| `asChild` | `boolean` | `false` | Renders as the child element instead of a `<button>` |

### CollapsibleContent

| Prop        | Type        | Default | Description                                              |
| ----------- | ----------- | ------- | -------------------------------------------------------- |
| `className` | `string`    | —       | Additional CSS classes                                   |
| `children`  | `ReactNode` | —       | Content revealed on open, animated via `collapsible.css` |

## Notes

Ships a companion `collapsible.css` (installed to `styles/collapsible.css`) defining the `collapsible-down`/`collapsible-up` keyframes the open/close animation uses. It's imported automatically by `collapsible.tsx` — no extra setup needed, and it doesn't depend on a consumer's Tailwind config defining `--animate-*` theme tokens.
