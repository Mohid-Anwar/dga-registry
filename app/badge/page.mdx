# Badge

Displays a badge or a component that looks like a badge.

## Installation

<InstallCommand componentName="badge" />

## Variants

| Variant       | Description             |
| ------------- | ----------------------- |
| `default`     | Primary badge           |
| `secondary`   | Secondary style         |
| `destructive` | Dangerous / error state |
| `outline`     | Bordered badge          |
| `ghost`       | No background           |
| `link`        | Styled as a link        |

<BadgeVariants />

## Chip Variants

DGA-specific chip styles for selection and filtering contexts.

| Variant                  | Description                |
| ------------------------ | -------------------------- |
| `chip-primary`           | Primary chip               |
| `chip-primary-active`    | Primary chip (active)      |
| `chip-primary-selected`  | Primary chip (selected)    |
| `chip-primary-pressed`   | Primary chip (pressed)     |
| `chip-neutral`           | Neutral chip               |
| `chip-neutral-selected`  | Neutral chip (selected)    |
| `chip-on-color`          | Chip on colored background |
| `chip-on-color-selected` | On-color chip (selected)   |
| `chip-disabled`          | Disabled chip              |

<BadgeChips />

## Rounded

| Rounded | Description                     |
| ------- | ------------------------------- |
| `full`  | Fully rounded corners (default) |
| `sm`    | Slightly rounded corners        |

<BadgeRounded />

## Sizes

| Size      | Description       |
| --------- | ----------------- |
| `default` | Inline text badge |
| `sm`      | 20px height       |
| `md`      | 24px height       |
| `lg`      | 32px height       |

<BadgeSizes />

## With Icons

Badges with leading or trailing icons.

<BadgeWithIcons />

## As Link

Use `asChild` to render the badge as an anchor or any other element.

<BadgeAsLink />

## RTL Support

Badges follow the ambient text direction. Set `dir="rtl"` on a parent element
to lay them out right-to-left.

<BadgeRtl />

## Props

| Prop        | Type      | Default     | Description                    |
| ----------- | --------- | ----------- | ------------------------------ |
| `variant`   | `string`  | `"default"` | Visual style variant           |
| `size`      | `string`  | `"default"` | Badge size                     |
| `rounded`   | `string`  | `"full"`    | Corner radius                  |
| `asChild`   | `boolean` | `false`     | Merge props onto child element |
| `className` | `string`  | —           | Additional CSS classes         |
